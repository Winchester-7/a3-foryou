# A3 FOR YOU — интернет-магазин керамогранита (Бишкек)

Премиальный магазин керамогранита для рынка Кыргызстана. Ассортимент — три бренда
ГК «Уральский Гранит»: **IDALGO**, **GRANITEA** и **«Уральский Гранит»**, плюс
межкомнатные двери **Diford** и мягкая мебель **Delavega**.

## Разделы, добавленные во 2-й итерации (поверх существующего проекта)

| Раздел | Маршрут | Источник данных |
|---|---|---|
| **Двери** | `/doors`, `/doors/[slug]` | `Каталог 2025 Diford` (PDF) — 25 моделей, стили, ДГ/ДО, цвета покрытия, размеры полотна |
| **Диваны** | `/sofas`, `/sofas/[slug]` | `DELAVEGA_web` (PDF) — 10 диванов + 7 кресел, каркас/ножки/наполнитель, размеры, ткани |
| **Создать свой интерьер (3D)** | отдельное приложение `planner/` → https://a3-foryou-3d.netlify.app (`/configurator` перенаправляет туда) | Размеры помещения → 3D-комната с реальной плиткой, двери, мебель, расчёт м², отправка в корзину/WhatsApp |
| **Каталог Алматы** | `/catalog-almaty` | тот же каталог + условия доставки в Казахстан (пилл-кнопка в шапке) |
| **Выбор цвета товара** | на страницах керамогранита / дверей / диванов | цветовые переключатели, смена активного варианта и изображения |
| **Hero-видео** | главная | Видео шоурума (Artlist, Kling 3.0, бесшовный цикл 10 с) + интерактивные плиты: при наведении прожектор выделяет плиту, подпись ведёт в раздел каталога |
| **Корзина** | шапка → выезжающая панель | Керамогранит (м² / шт.), двери и диваны (шт.); хранится в `localStorage`; список отправляется в WhatsApp или на почту одним сообщением |

Изображения дверей/диванов извлечены из PDF (`public/doors`, `public/sofas`);
hero-видео и постер — `public/hero/hero-showroom.{mp4,jpg}`.
Существующий дизайн, структура, каталог керамогранита, анимации и страницы не изменялись.

## Стек

- **Next.js 14** (App Router) · **React 18** · **TypeScript**
- **Tailwind CSS** — токены в `tailwind.config.ts`, акцентный цвет `#E0241B` (красный логотипа)
- **Motion** (`motion/react`, бывш. Framer Motion) — токены кривых в `src/lib/motion.ts` и `globals.css`; появление блоков при скролле, hover-анимации, mega-menu, поиск, quick view, параллакс
- Шрифт **Inter** (`next/font/google`, латиница + кириллица)
- Полностью адаптивно, SEO: metadata API, JSON-LD (Organization / CollectionPage / ProductGroup / Product / BreadcrumbList), `sitemap.ts`, `robots.ts`

## Данные каталога

Реальные данные извлечены из PDF-каталогов производителя (`generalnyy_gk_ug_2025`,
`novinki_idalgo_2025`, `katalog_granitea_2026`) через рендер страниц + OCR (Tesseract rus+eng)
и разбор оглавления:

- **53 коллекции** в `src/lib/collections.ts` — реальные названия (RU + EN), артикулы GRANITEA/УГ,
  форматы (1200×600, 600×600, 1200×195, 300×300…), поверхности (матовая / лаппатированная /
  полированная / структурная / рельефная), толщина, области применения.
- **~230 декоров** (цветовых вариантов) с описаниями и характеристиками.
- **Технические характеристики** (`src/lib/specs.ts`) — по ГОСТ 13996-2019, класс BIa:
  водопоглощение ≤ 0,07%, прочность на изгиб 47 МПа, морозостойкость F100–F200, PEI 4, R9–R12.
- **Фотографии** — извлечены из PDF (JPEG-2000 → JPEG), разложены в `public/catalog/<slug>/`:
  `hero.jpg` (интерьерный кадр коллекции), `g1..g8.jpg` (галерея), `s1..s8.jpg` (выкладки плитки).
  Карточки декоров используют фото из своей коллекции (сопоставление по развороту каталога).

> **Цены** в каталогах производителя отсутствуют → на сайте везде «Цена по запросу» + форма заявки
> и кнопки WhatsApp. Подставьте свои цены в `Product` / уберите `PRICE_LABEL`, если нужно.

## Структура

```
src/
  app/
    page.tsx                 главная (Hero-параллакс + секции)
    catalog/                 каталог: индекс + [category] (9 категорий: под дерево/камень/мрамор/
                             лофт/бетон, для фасадов/террас/ванной/кухни) — грид коллекций + фильтры
    collection/[slug]/       страница коллекции: баннер, характеристики, грид декоров, галерея интерьеров
    product/[slug]/          страница декора: галерея с зумом, характеристики, PDF, форма, WhatsApp
    interior/                «Интерьер и мебель»: 5 категорий (диваны, двери, раковины, смесители,
                             мебель для ванной) — кураторская подборка (изображения-плейсхолдеры)
    where-to-buy · about · news · promotions
    api/lead/route.ts        приём заявок (демо)
    sitemap.ts · robots.ts
  components/
    layout/     Sticky Header + Mega Menu + мобильное меню (кнопка звонка + WhatsApp), Footer, Breadcrumbs,
                FloatingContacts (фикс. WhatsApp + звонок + наверх)
    catalog/    CollectionCard, ProductCard, CatalogView (фильтры коллекций), ProductGrid, QuickView, Filters, CategoryBanner
    product/    ProductGallery (зум по наведению), ProductActions
    home/       Hero, CategoryShowcase, FeaturedProducts, EditorialSplit, Advantages, InteriorTeaser, NewsTeaser, CtaSection
    forms/      LeadDialog + LeadForm (заявка / обратный звонок / консультация)
    media/      TileImage (next/image, локальные фото), ParallaxImage, Photo (picsum — для раздела «Интерьер»)
    motion/     Reveal, StaggerGroup/StaggerItem — «видимо по умолчанию», без риска пустых блоков
  lib/          site.ts, catalog.ts (looks + categories + accessors), collections.ts (данные),
                catalog-images.json (карта фото), specs.ts, interior.ts, editorial.ts, media.ts, types.ts
```

## Что заменить перед продакшеном

1. `src/lib/site.ts` — точный адрес шоурума, e-mail, соцсети, домен.
2. Фотографии коллекций в `public/catalog/` — на съёмку в высоком разрешении
   (сейчас — кадры из PDF, 760–1440 px).
3. Раздел «Интерьер и мебель» (`src/lib/interior.ts`) — на реальный ассортимент партнёров и их фото.
4. `src/app/api/lead/route.ts` — интеграция с CRM / WhatsApp Business API / почтой.
5. `public/catalog-a3-foryou.pdf` — реальный каталог.
6. Цены — если появятся, добавьте поле в `Product` и обновите карточки.
