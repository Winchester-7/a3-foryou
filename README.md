# A3 FOR YOU — интернет-магазин керамогранита (Бишкек)

Автор проекта: **Erbol king**

Сайт A3 FOR YOU: каталог керамогранита «из наличия на складе», двери, диваны, портфолио,
3D-планировщик интерьера, корзина с отправкой заказа в WhatsApp и управление каталогом
через Telegram-бота. Два языка интерфейса — русский и кыргызский.

## Состав репозитория

| Папка | Что внутри |
|---|---|
| `src/` | Магазин на Next.js 14 (App Router, TypeScript, Tailwind, Motion) |
| `src/data/` | **Данные каталога в JSON** — их правит бот и импортёры (см. ниже) |
| `planner/` | 3D-планировщик (Vite + React Three Fiber), отдельный сайт |
| `public/` | Фото плит (`tiles/`), двери (`doors2/`), диваны (`sofas/`), логотипы (`brands/`), hero-видео |

## Запуск

```bash
npm install
npm run dev          # сайт на http://localhost:3000
npm run build && npm start
```

Планировщик:

```bash
cd planner
npm install
npm run data         # выгрузить каталог сайта в планировщик (после изменения src/data)
npm run dev
```

## Данные

| Файл | Содержимое |
|---|---|
| `src/data/tiles.json` | Коллекции и позиции керамогранита, остатки по форматам и поверхностям |
| `src/data/doors.json` | Межкомнатные и входные двери |
| `src/data/sofas.json` | Диваны и кресла |
| `src/data/portfolio.json` | Проекты для раздела «Портфолио» |

Каталог керамогранита собран из складской таблицы остатков: на сайте только то, что
есть в наличии. Фото позиций взяты с сайтов заводов (uralgres.com, kerranova.ru,
grasaro.ru). Позиции без найденного фото показываются с заглушкой «Фото скоро» — фото
можно добавить через бота (`/photo`).

Логотипы производителей (`public/brands/`) выводятся на карточках, в фото товара,
в фильтре брендов и в шапке каталога — компонент `src/components/brand/BrandLogo.tsx`.

## Языки

Страницы отдаются на русском; кнопка **РУС / КЫР** в шапке переводит интерфейс на лету.
Словарь — `src/lib/i18n/ky.ts` (для планировщика — `planner/src/i18n/ky.ts`).
Названия коллекций, моделей и артикулы не переводятся. Чтобы перевести новую фразу,
добавьте её в словарь: ключ — русский текст, значение — кыргызский.

## Telegram-бот управления сайтом

Бот работает как webhook на `/api/telegram` и вносит изменения коммитами в этот
репозиторий (JSON-файлы в `src/data/` и загруженные фото в `public/uploads/`).
После коммита Netlify пересобирает сайт сам — изменения видны через 1–3 минуты.

Переменные окружения (Netlify → Site configuration → Environment variables):

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | любая длинная случайная строка |
| `TELEGRAM_ADMIN_IDS` | Telegram ID администраторов через запятую |
| `GITHUB_TOKEN` | fine-grained токен с правом **Contents: Read and write** на этот репозиторий |
| `GITHUB_REPO` | `владелец/репозиторий`, например `Winchester-7/a3-foryou` |
| `GITHUB_BRANCH` | `main` (по умолчанию) |

После деплоя один раз откройте в браузере
`https://<адрес сайта>/api/telegram?key=<TELEGRAM_WEBHOOK_SECRET>` — это зарегистрирует webhook.
Свой Telegram ID можно узнать, написав боту любое сообщение: он ответит «Нет доступа» и покажет ID.

Команды (подробно — `/help` в самом боте):

```
/tiles [поиск]             список позиций керамогранита
/add_tile                  добавить позицию (фото + подпись «Ключ: значение»)
/del_tile slug             удалить позицию
/stock slug 1200x600 450   изменить остаток (м²)
/photo slug                прикрепить фото к позиции
/doors · /add_door · /del_door slug
/sofas · /add_sofa · /del_sofa slug
/projects · /add_project · /del_project slug
```

## Домен и общая работа с B2B-сайтом

DNS домена a3.kg находится в Cloudflare и обслуживает B2B-сайт для дилеров. Магазин
размещается на отдельном адресе (поддомен) через одну CNAME-запись на Netlify — так он
не затрагивает существующую базу, почту и записи DNS. Данные дилерской базы магазин
не читает и не пишет.
