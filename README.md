# A3 FOR YOU — интернет-магазин керамогранита (Бишкек)

Автор проекта: **Erbol king**

Сайт A3 FOR YOU: каталог керамогранита «из наличия на складе», двери, диваны, портфолио,
3D-планировщик интерьера, корзина с отправкой заказа в WhatsApp, встроенная админ-панель
для управления содержимым и два языка интерфейса — русский и кыргызский.

## Состав репозитория

| Папка / файл | Что внутри |
|---|---|
| `src/` | Магазин и админ-панель на Next.js 14 (App Router, TypeScript, Tailwind, Motion) |
| `src/data/` | Начальные данные каталога (JSON) — с них стартует пустое хранилище |
| `src/lib/store.ts` | Хранилище: JSON-файлы в `DATA_DIR`, чтение с проверкой времени изменения |
| `src/app/admin`, `src/app/api/admin` | Админ-панель и её API |
| `planner/` | 3D-планировщик (Vite + React Three Fiber), отдельное приложение |
| `Dockerfile`, `docker-compose.yml`, `.gitlab-ci.yml`, `deploy/` | Сборка образа, поставка на сервер, Nginx |
| `docs/DEPLOY.md` | Развёртывание, резервные копии, работа с админкой |
| `scripts/import/` | Скрипты первичного импорта каталога (Excel остатков, сайты заводов) |

## Запуск

```bash
npm install
npm run dev                     # http://localhost:3000, данные из src/data (только чтение)

# с хранилищем и админ-панелью:
DATA_DIR=./.data ADMIN_PASSWORD=секрет npm run dev
# затем http://localhost:3000/admin
```

Планировщик:

```bash
cd planner
npm install
npm run data         # выгрузить каталог сайта в планировщик
npm run dev
```

## Как устроены данные

Страницы собираются на сервере при каждом запросе из JSON-файлов хранилища
(`tiles`, `doors`, `sofas`, `portfolio`, `promotions`, `settings`, `leads`).
Админ-панель пишет в те же файлы атомарно, поэтому правки видны сразу.
Если `DATA_DIR` не задан (локальный просмотр, демо на Netlify), используются данные,
вшитые в сборку, а сохранение отключено.

Каталог керамогранита собран из складской таблицы остатков; фото позиций взяты с сайтов
заводов (uralgres.com, kerranova.ru, grasaro.ru). Позиции без фото показываются с заглушкой
«Фото скоро» — фото добавляется в админ-панели. Свежую таблицу остатков можно загрузить
прямо в админ-панели (раздел «Остатки Excel», код — `src/lib/stock-import.ts`). Логотипы производителей — `public/brands/`,
компонент `src/components/brand/BrandLogo.tsx`.

## Языки

Страницы отдаются на русском; кнопка **РУС / КЫР** в шапке переводит интерфейс на лету.
Словарь — `src/lib/i18n/ky.ts` (для планировщика — `planner/src/i18n/ky.ts`).
Названия коллекций, моделей и артикулы не переводятся.

## Домен

DNS домена a3.kg находится в Cloudflare; приложения дилерской системы (`app.a3.kg`,
`backend.a3.kg`) остаются как есть. Подробности про Docker, GitLab CI/CD и Nginx —
в `docs/DEPLOY.md`.
